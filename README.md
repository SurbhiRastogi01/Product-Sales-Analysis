# Product Sales Analysis
## Project Overview
this project analyses product sales data using Python to identify sales trends, product performance, regional performance, and operational insights.
The analysis was performed using Python, Pandas, NumPy, Matplotlib, and seaborn.
## Objectives
- Analyze overall sales performance
- Identify top- performing products
- Compare sales across regions
- Analyze salesperson performance
- Study monthly sales trends
- Analyze returns and payment methods
- Analyze promotions and discounts
- Evaluate delivery and shipping costs
- Generate actionable business insights
